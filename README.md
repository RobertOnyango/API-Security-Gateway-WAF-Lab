# API-Security-Gateway-WAF-Lab

Build two APIs, expose them through APIM, configure WAF and demonstrate authentication, authorisation and attack prevention.

- Resource group and virtual network — already created.
- Application Gateway WAF v2 — our internet-facing security gateway.
- Azure API Management — our API gateway.
- Backend Web Apps — Patient Records API and Appointments API.
- Private Endpoints and Private DNS.
- Connect the components and configure security policies.
- Validate the complete traffic flow and capture evidence.
